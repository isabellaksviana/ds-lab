# Tokens

Tokens são as decisões visuais do ds-lab guardadas em variáveis CSS: cores, fontes e arredondamento. Os componentes não usam valor solto. Quando uma decisão muda, ela muda no token, e todo componente que usa o token acompanha.

## Como usar

Importe os estilos do DS uma vez, na entrada do projeto. Os tokens vêm junto:

```js
import 'ds-lab/styles.css';
```

Se o projeto só precisar dos tokens, sem os componentes:

```js
import 'ds-lab/tokens.css';
```

Depois, use o token pelo nome, nunca o valor:

```css
.meu-bloco {
  background: var(--surface);
  color: var(--text);
  border: 1px solid var(--border);
  border-radius: var(--radius-lg);
}
```

## Temas

O ds-lab tem dois temas, e **o escuro é o padrão**. Quem escolhe o tema é o atributo `data-theme` no `<html>`:

```html
<html data-theme="dark">  <!-- ou "light" -->
```

Os nomes dos tokens são os mesmos nos dois temas, só os valores mudam. Por isso um componente não precisa saber em que tema está. Nas amostras abaixo, cada token mostra os dois valores: **escuro** à esquerda, **claro** à direita.

## Cores

**Todo texto passa de 7:1 de contraste** sobre o fundo em que aparece, nos dois temas (nível AAA da WCAG). É mais que o mínimo comum (4,5:1), pra leitura ficar confortável pra qualquer pessoa, inclusive com baixa visão. A única exceção é o botão desabilitado.

### Versões suaves e texto em cima de cor

Os tokens `-soft` são o fundo dos chips (tags e badges). São **cores fixas, não transparentes**: com transparência, o chip mudaria de cor conforme o fundo, e o texto podia cair abaixo de 7:1 em cima de um cartão.

Os tokens `on-` são o texto que vai **em cima** de uma cor de destaque. Por exemplo, `--on-primary` é o texto do botão principal.

## Tipografia

<table>
  <thead>
    <tr><th>Token</th><th>Fonte</th><th>Uso</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><code>--font</code></td>
      <td style={{ fontFamily: 'var(--font)', fontSize: '1.125rem' }}>Inter</td>
      <td>Todo o texto da interface.</td>
    </tr>
    <tr>
      <td><code>--font-mono</code></td>
      <td style={{ fontFamily: 'var(--font-mono)', fontSize: '1rem' }}>JetBrains Mono</td>
      <td>Código e rótulos curtos de apoio (datas, assinatura). Nunca em título ou texto corrido.</td>
    </tr>
  </tbody>
</table>

As fontes não vêm embutidas no DS: o projeto carrega Inter e JetBrains Mono (pelo Google Fonts, por exemplo). Se não carregar, cada token tem fontes de reserva do sistema.

## Arredondamento

Arredondamento vem sempre de token, nunca de número solto.

<div style={{ display: 'flex', gap: '2rem', flexWrap: 'wrap', margin: '1.5rem 0' }}>
  {[
    ['--radius-sm', '4px', 'Tags, badges e o contorno de foco'],
    ['--radius-md', '8px', 'Botões e controles'],
    ['--radius-lg', '12px', 'Cards e blocos grandes'],
  ].map(([name, size, use]) => (
    <div key={name} style={{ width: '12rem' }}>
      <div
        style={{
          height: '5rem',
          border: '2px solid var(--primary)',
          background: 'var(--primary-soft)',
          borderRadius: `var(${name})`,
        }}
      />
      <p style={{ margin: '0.75rem 0 0' }}>
        <code>{name}</code> · {size}
      </p>
      <p style={{ margin: '0.25rem 0 0', fontSize: '0.875rem' }}>{use}</p>
    </div>
  ))}
</div>
