As fontes não vêm embutidas no DS: o projeto carrega Inter e JetBrains Mono (pelo Google Fonts, por exemplo). Se não carregar, cada token tem fontes de reserva do sistema.

O texto base tem 16px (`1rem`), e as medidas são em `rem`: assim a interface respeita o zoom e o tamanho de fonte escolhido no navegador.
